# Songchen Jiang Homepage

This repository contains a Hugo Blox version of Songchen Jiang's academic homepage, migrated from the previous AcademicPages/Jekyll site and adapted from the target Hugo Blox template.

## Bilingual mode

English/Chinese switching is enabled. The English site is served at `/`; the Chinese site is served at `/zh/`.

Primary files to edit:

- English homepage: `content/_index.md`
- Chinese homepage: `content/zh/_index.md`
- English author profile: `data/authors/me.yaml`
- Chinese author profile: `data/authors/me_zh.yaml`
- Publications: `content/publications/` and `content/zh/publications/`
- Projects: `content/projects/` and `content/zh/projects/`

Deploy through GitHub Pages with **GitHub Actions**.
